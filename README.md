## Overview

A surrogate neural network that predicts zombie outbreak outcomes for North Carolina counties using real census-derived Human Survivability Index (HSI) data. Instead of running a slow SZR epidemiological simulation at inference time, the trained MLP approximates the simulation output in milliseconds.

The project satisfies the first option of the assignment — **training an AI from scratch on a unique dataset** — using synthetic data generated by running thousands of SZR simulations with parameters anchored to real NC census data.

**Live app:** Deployed on GCP Cloud Run via Docker + GitHub Actions CI/CD

**Repo:** https://github.com/ckmoore2/Project-2-SZR-Outbreak-Outcome-Predictor

---

## What It Does

Given eight input features describing an NC county and outbreak scenario, the model simultaneously predicts:
- **Peak zombie fraction** — maximum fraction of the population that becomes infected at any point
- **Time to peak** — day on which the zombie population peaks
- **Containment probability** — binary classifier: does the susceptible population stabilise above 10%?

The Streamlit app provides interactive controls for county selection, zombie show scenario presets, outbreak severity levels, and fine-tune parameter sliders.

## Architecture

```
SZRPredictor (Experiment C — best model)
  Input (8 features)
  → Linear(8 → 64) → ReLU → Dropout(0.2)
  → Linear(64 → 128) → ReLU → Dropout(0.2)
  → Linear(128 → 3)
     ├── outputs[0:2] → peak_zombie_fraction, time_to_peak  (MSE loss)
     └── outputs[2]   → containment logit                   (BCEWithLogitsLoss, pos_weight=5.5)
```

## The HSI (Human Survivability Index)

The HSI is a composite score computed from six categories of real NC census data, weighted as follows:

| Category | Weight | Data Sources |
|---|---|---|
| H — Health & Fitness | 0.15 | CDC PLACES 2023 (obesity, inactivity), ACS B18105 (disability), CMS nursing home density |
| M — Mobility & Escape | 0.15 | ACS B25044 (vehicle access), USDA RUCA rural codes, road density |
| I — Infrastructure | 0.20 | RUCA proxy for self-sufficiency, grid independence, food access |
| E — Education & Awareness | 0.10 | ACS S1501 attainment, Alone/Survivor TV show occupational survival proxy |
| C — Social & Community | 0.25 | VA VetPop 2024, NICS gun sales, DoD DMDC military personnel, congregation density |
| G — Geographic | 0.15 | NOAA 143-station IDW interpolation → elevation, precipitation, survivability |

**HSI formula:**
```
HSI_raw = 0.15×H + 0.15×M + 0.20×I + 0.10×E + 0.25×C + 0.15×G
HSI     = (HSI_raw − min) / (max − min)   → [0, 1] across NC counties
```

**Effect on SZR parameters (v2 sigmoid modifier):**
```
κ_eff(tract) = κ_base × sigmoid_modifier(HSI)
β_eff(tract) = β_base × (1 + 0.40×density) × (1 − 0.25×mobility_score)
```

The sigmoid modifier captures threshold effects — communities above HSI=0.5 become dramatically more effective at zombie removal, not just marginally better.

## Dataset Generation (v2)

The synthetic training data is generated by `data/generate_data.py` which now:

1. **Loads real NC HSI distributions** from `data/processed/hsi_distributions.json`, produced by `data/integrate_real_hsi.py` from the team's merged county DataFrame.
2. **Samples HSI sub-scores** from clipped normal distributions anchored to actual NC county means and standard deviations — not wide uniform ranges.
3. **Stratifies across five zombie scenario profiles** (The Walking Dead, The Last of Us, World War Z, 28 Days Later, Rabies) so the model trains on diverse outbreak dynamics.
4. **Derives per-scenario beta and kappa** from HSI rather than randomizing them independently.

This ensures synthetic training examples are drawn from the same distribution as real NC counties, making the model's predictions more meaningful for actual county-level inputs.

## Ablation Experiments

Six ablation experiments were run to validate model design:

| Experiment | Description | MAE | RMSE | R² | F1 | AUC |
|---|---|---|---|---|---|---|
| A | Linear/Logistic baseline | 7.32 | 17.02 | 0.625 | 0.997 | 1.000 |
| B | MLP [32] | 6.18 | 15.46 | 0.697 | 0.949 | 1.000 |
| C | **MLP [64, 128] ← primary model** | **2.07** | **7.80** | **0.892** | **0.980** | **0.999** |
| D | MLP [128, 256, 128] | 1.17 | 4.83 | 0.925 | 0.971 | 0.999 |
| E | MLP [64, 128], **no HSI features** | 1.89 | 7.30 | 0.916 | 0.984 | 0.999 |
| F | MLP [64, 128], **only HSI features** | 9.83 | 20.86 | −0.001 | 0.646 | 0.507 |

**Key finding:** HSI-only (Exp F) completely fails (R² ≈ 0), confirming that epidemiological parameters drive outcomes — HSI modulates them. Removing HSI entirely (Exp E, R²=0.916) has minimal impact on regression but HSI features improve containment classification (F1 0.980 vs 0.984, AUC maintained). Exp D outperforms C but C is selected as the primary model (simpler architecture, faster inference, near-equivalent quality).

## Model Improvements (v1 → v2)

**1. Sigmoid κ modifier** (was linear)
- v1: `κ_eff = κ_base × (1 + 0.5 × HSI)` — proportional, range [1.0, 1.5]×κ_base
- v2: `κ_eff = κ_base × sigmoid_modifier(HSI)` — captures coordination threshold at HSI=0.5

**2. Tract-level β variation** (was uniform)
- v1: β constant everywhere regardless of density or mobility
- v2: `β_eff = β_base × (1 + 0.40×density) × (1 − 0.25×mobility)` — gives M section direct influence on spread rate

**3. Real HSI distribution anchoring** (was random)
- v1: HSI sub-scores sampled from uniform [0, 1]
- v2: Sampled from clipped normals anchored to real NC county distributions

## SZR Model Note

The app uses a **frequency-dependent** SZR formulation:
```
dS/dt = −β × S × Z / N
dZ/dt =  β × S × Z / N − (κ + α) × Z
dR/dt =  (κ + α) × Z
```

The simulation notebook (`Model_Simulation_1.ipynb`) uses a **mass-action** formulation without the `/N` denominator. The frequency-dependent form is more standard for human diseases and scales correctly across county populations of different sizes.

## Setup & Run

### Prerequisites
```bash
pip install -r requirements.txt
```

### Generate data and train
```bash
# Step 1 — Export merged DataFrame from notebook first:
#   In Model_Simulation_1.ipynb, add and run:
#   df.to_csv("data/processed/merged_county_df.csv", index=False)

# Step 2 — Extract real NC HSI distributions
python data/integrate_real_hsi.py

# Step 3 — Generate 10,000 synthetic training scenarios
python data/generate_data.py

# Step 4 — Train all six ablation experiments, save best model
python model/train.py
```

### Run the app locally
```bash
streamlit run app/streamlit_app.py
```

### Deploy to GCP Cloud Run
Push to `main` branch — GitHub Actions builds the Docker image and deploys automatically.

> **Mac Apple Silicon note:** Docker builds targeting Cloud Run must use `--platform linux/amd64`
